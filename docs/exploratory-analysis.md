# Exploratory Analysis

The exploratory analysis will be recorded in
`artifacts/notebooks/01_EDA.ipynb`.

## Planned workflow

1. Check dimensions, data types, and grain.
2. Assess data quality and duplicate records.
3. Examine class distributions only for understanding and future evaluation.
4. Analyze numerical and categorical features.
5. Investigate correlations, redundancy, and scales.
6. Compare traffic profiles without using the label as a clustering feature.
7. Record hypotheses for preparation and modeling.

## Future outputs

- tables in `artifacts/tables/`;
- static images in `artifacts/images/`;
- interactive charts reconstructed by Streamlit;
- decisions documented in the notebook and on this page.

The notebook does not yet contain approved results. Exploratory charts or figures must
not be treated as final conclusions.
