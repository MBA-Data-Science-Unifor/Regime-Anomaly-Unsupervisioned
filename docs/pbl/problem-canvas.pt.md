# Canvas do Problema

## Problema

Identificar regimes operacionais recorrentes e observações incomuns de consumo de
energia em um conjunto de dados de uma indústria siderúrgica sem usar os valores de
`Load_Type` para treinar os modelos não supervisionados.

## Usuários

- analistas que investigam o comportamento energético industrial;
- equipes responsáveis pelo planejamento energético e pela revisão operacional;
- avaliadores acadêmicos da metodologia do projeto.

## Valor esperado

- entendimento reproduzível dos padrões de energia e qualidade da potência;
- perfis interpretáveis de três regimes;
- observações priorizadas para investigação;
- documentação transparente das premissas e limitações.

## Restrições

- dados históricos de um único contexto industrial;
- ausência de rótulos causais ou de falha de equipamento;
- os três regimes são uma hipótese do problema, não uma verdade física comprovada;
- a contaminação de anomalias é atualmente uma premissa exploratória;
- não existe validação financeira ou de produção.

## Evidências necessárias

- fonte e contrato dos dados;
- EDA revisada e descobertas iniciais;
- preparação sensível ao tempo;
- comparação de modelos e estabilidade;
- avaliação externa congelada;
- limitações e análise de falhas;
- manifesto reproduzível dos artefatos.
